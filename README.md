One emoji, one smile: 🤗 — a hug for a stranger. The entry is the single emoji in entry.txt (1 of 8 characters); main.ts is a small guard that validates it and hands it in.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# prints the emoji, its code point and the budget left, and writes out/entry.txt
```
